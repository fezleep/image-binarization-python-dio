# exemplo de uso

antes de executar o projeto, coloque uma imagem colorida chamada `imagem.jpg` dentro da pasta:

```text
images/input/
```

o caminho final deve ficar assim:

```text
images/input/imagem.jpg
```

depois rode o script principal:

```bash
python src/main.py
```

os arquivos gerados serão salvos em:

```text
images/output/grayscale.png
images/output/binary.png
```

se a imagem de entrada não existir, o programa vai mostrar uma mensagem de erro no terminal.
